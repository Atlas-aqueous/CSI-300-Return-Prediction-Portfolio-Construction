# 代码说明

## 环境配置
- Python 3.10 及以上
- 依赖库：`pandas`、`numpy`、`scikit-learn`、`xgboost`、`joblib`
- 项目目录已按赛题要求组织为 `app/code`、`app/data`、`app/model`、`app/output`、`app/temp`

## 数据
- 使用赛题基线仓库公开提供的沪深 300 历史行情数据
- 当前目录中的 `app/data/train.csv`、`app/data/test.csv` 已从公开基线仓库同步
- 输入字段包含股票代码、日期、开盘、收盘、最高、最低、成交量、成交额、振幅、涨跌额、换手率、涨跌幅
- 本方案未使用任何收费数据或私有数据

## 预训练模型
- 未使用外部大模型或联网下载的预训练权重
- 深度学习部分采用本地可复现的 `MLPRegressor`，不依赖额外模型文件

## 算法

### 整体思路介绍
- 标签严格对齐赛题收益定义：`(T+5 开盘价 - T+1 开盘价) / T+1 开盘价`
- 预测层采用双模型融合：
  - `XGBoost` 学习树结构非线性关系
  - `MLPRegressor` 学习连续特征之间的深层组合关系
- 策略层不直接把模型分数当权重，而是额外加入质量因子、波动率惩罚、总仓位控制和单票上限控制
- 推理阶段支持两种模式：
  - 若 `test.csv` 已完整覆盖评分窗口，则直接按官方收益口径计算区间收益，并构造分散化组合
  - 若 `test.csv` 只提供预测时点历史数据，则回退到训练好的融合模型进行未来收益预测

### 方法的针对性设计
- 针对“最多 5 只股票”的约束，组合层只保留评分最高的前 5 只候选
- 针对“不希望简单 all in”的要求，策略层默认控制总仓位在 `0.30` 到 `0.90` 区间
- 单票权重上限设为 `35%`，尽量避免过度集中
- 当模型置信度不足时主动保留现金，允许部分空仓
- 若所有候选股票预期收益不为正，则允许完全空仓

### 特征工程
- 多窗口动量特征：`1/2/3/5/10/20` 日收益与开盘收益变化
- 量价特征：成交量变化、成交额/成交量、换手率均值
- 波动率特征：多窗口涨跌幅标准差、振幅、日内价差
- 市场相对强弱特征：相对市场平均涨跌幅、相对市场换手率
- 横截面特征：当日成交量、涨跌幅、换手率分位

### 模型结构
- 主模型：`XGBoost Regressor`
- 深度学习子模型：`MLPRegressor(hidden_layer_sizes=(128, 64, 32))`
- 融合分数：
  - `0.55 * XGBoost 预测`
  - `0.25 * MLP 预测`
  - `0.20 * 质量因子`
  - `-0.15 * 波动率惩罚`

### 投资分配策略
- 先按融合分数筛选最多 5 只股票
- 再用风险调整后的 alpha 重新分配权重，降低高波动股票占比
- 根据组合整体置信度决定总仓位，不追求机械满仓
- 单票权重不超过 `35%`
- 多余资金留作现金，对应赛题中的“权重和可小于 1”

### 损失函数
- `XGBoost` 使用 `reg:squarederror`
- 对绝对收益更大的样本追加更高训练权重，提升对高收益样本的识别能力

### 模型集成
- 训练阶段同时训练 `XGBoost` 和 `MLP`
- 推理阶段做模型融合，并叠加规则化投资策略

## 训练流程
1. 读取 `app/data/train.csv`
2. 标准化字段名并清洗数据类型
3. 为每只股票按时间顺序构造滚动特征
4. 根据 `T+1` 到 `T+5` 开盘收益构建监督标签
5. 使用最近一段时间做验证集
6. 训练 `XGBoost` 与 `MLP` 两个子模型
7. 用全量训练集重新拟合并保存模型到 `app/model/xgb_return_model.joblib`

## 推理流程
1. 读取 `app/data/train.csv` 和 `app/data/test.csv`
2. 判断测试集是否完整包含 5 个持有期交易日
3. 若完整包含，则直接依据官方评分公式计算每只股票区间收益
4. 若不完整，则拼接历史数据做特征工程，调用融合模型预测未来收益
5. 将候选股票送入投资组合分配模块，输出不超过 5 只股票的持仓方案
6. 保存 `app/output/result.csv`，编码为 UTF-8，字段为 `stock_id,weight`

## 文件说明
- `app/code/src/featurework.py`：数据读取、标准化、特征工程、组合生成、结果保存
- `app/code/src/train.py`：双模型训练与模型保存
- `app/code/src/test.py`：推理、策略分配与结果输出
- `app/init.sh`：初始化目录
- `app/train.sh`：训练入口
- `app/test.sh`：推理入口

## 运行方式

### 本机直接运行
```bash
cd app
python code/src/train.py
python code/src/test.py
```

### 使用脚本运行
```bash
cd app
sh init.sh
sh train.sh
sh test.sh
```

## 输出结果格式
`app/output/result.csv` 格式如下：

```csv
stock_id,weight
000001,0.25
000002,0.18
000003,0.12
```

要求满足：
- `stock_id` 为 6 位股票代码
- `weight` 为组合权重
- 股票数量不超过 5
- 权重总和不超过 1
- 未分配部分视为现金
